# CPU Performance Analyzer Feature Map

## Core
- Authentication and user workspace
- CPU benchmark runner
- Integer, floating point, matrix, memory and multithread workloads
- Warm-up + 3 repetitions + median timing
- Normalized category scores and overall score
- System information

## Product UI
- Dashboard
- Benchmark runner with progress
- Results/analytics
- History
- Run-to-run comparison
- JSON export/import
- Cloud/remote run analyzer
- Methodology page
- Dark/light theme
- Responsive mobile layout

## Backend
- JWT auth
- Per-user run storage
- FastAPI REST API
- SQLAlchemy
- SQLite demo mode
- PostgreSQL-ready configuration

## Future/optional
- Emscripten WebAssembly production engine
- True pthread WebAssembly multithreading with cross-origin isolation
- Real cloud execution providers
- Public leaderboard with methodology disclosure
